\section*{Introduction}
I play badminton and practice bouldering, and I have been injured in both: shoulder strain from poor badminton smash mechanics, and knee misalignment plus shoulder overreach during dynamic bouldering moves. These injuries motivate this project because many sport injuries are linked to measurable, preventable joint-angle deviations. My goal is to build a real-time webcam system that classifies body poses into injury-risk categories without motion-capture equipment. Deep learning is appropriate because fixed angle rules do not generalize well across body sizes, camera views, and noisy keypoint predictions; an MLP can learn the injury-risk boundary from data. The same tool could support amateur athletes and lightweight human-robot interaction safety monitoring. Problem statement: given one webcam frame, classify the observed human pose into one of four clinically grounded injury-risk classes.

\section*{Background \& Related Work}
\textbf{REBA.} \citet{hignett2000reba} introduced a clinical postural scoring tool built from more than 600 postural examples. This project uses its trunk, neck, and upper-limb thresholds to generate biomechanically grounded labels instead of manual labels.

\textbf{BlazePose.} \citet{bazarevsky2020blazepose} showed that lightweight CNN pose estimation can run in real time on-device. This supports the choice of a frozen MoveNet-style backbone for fast webcam inference.

\textbf{HRNet.} \citet{sun2019hrnet} maintains high-resolution feature maps for accurate keypoint localization. My project trades some pose-estimation accuracy for CPU speed by using a lighter frozen pose model.

\textbf{Deep REBA.} \citet{chatzis2022automatic} estimated REBA scores from RGB-derived 3D skeletons using a variational deep network. My project keeps the skeleton-plus-REBA idea but solves a simpler 2D, four-class webcam problem.

\textbf{ConstructionPose3D.} \citet{fan2024cp3d} introduced a large construction-pose dataset for deep ergonomic assessment. My project extends pose-based risk classification to sports using consumer webcam data and no depth sensor. The gap is lightweight, real-time, sport-context injury-risk classification from monocular 2D pose with clinical labels.

\section*{Data Processing}
I will use MPOSE2021 \citep{mazzia2021action,mpose2021zenodo}, available from GitHub and Zenodo \citep{pic4ser2021mpose}. It has 15,429 samples, 20 action classes, and 100 subjects. The full array has shape \texttt{(N,30,17,3)}: samples, frames, keypoints, and $(x,y,confidence)$ values pre-extracted by OpenPose/PoseNet. No raw images are used; the MLP trains directly on keypoint vectors normalized to match MoveNet output.

First, I will reduce each 30-frame sequence to one representative pose by temporal averaging: \texttt{X\_avg = X.mean(axis=1)}, giving shape \texttt{(N,17,3)}, then flatten to \texttt{(N,51)}. Second, I will remove high-motion actions that cannot be assigned quasi-static ergonomic labels. The motion score is the mean frame-to-frame keypoint displacement, $\frac{1}{TJ}\sum_t\sum_j \|\mathbf{p}_{t+1,j}-\mathbf{p}_{t,j}\|_1$, and only low-motion samples will be retained. Third, I will discard all original action labels and generate labels from joint angles using $\theta=\arccos((\vec{BA}\cdot\vec{BC})/(\|\vec{BA}\|\|\vec{BC}\|))$.

Worst violation wins if several rules fire. I will filter missing/low-confidence keypoints, center each skeleton at the hip, scale by torso length, and use inverse-frequency class weights to address class imbalance. Evaluation will use an 80/20 train/validation split and a small manually labelled webcam test set.

\section*{Architecture}
Stage 1 is MoveNet \citep{tensorflowmovenet}, pretrained and frozen. It takes a $192\times192\times3$ RGB frame and outputs a 51-dimensional keypoint vector; its weights are not updated. Stage 2 is my PyTorch MLP: \texttt{Linear(51,128)} $\rightarrow$ ReLU $\rightarrow$ Dropout(0.3) $\rightarrow$ \texttt{Linear(128,64)} $\rightarrow$ ReLU $\rightarrow$ Dropout(0.3) $\rightarrow$ \texttt{Linear(64,4)}. The output is a four-class probability distribution after softmax. I will train with weighted cross-entropy loss, Adam with learning rate 0.001, 50 epochs, early stopping with patience 10, and validation-based tuning. An MLP fits this problem because the input is a structured numerical vector, not an image grid; a CNN would impose unnecessary spatial assumptions.

\section*{Baseline Model}
The baseline is a deterministic REBA-rule classifier with no learned parameters. It computes the same neck, trunk, upper-arm, and knee angles, applies the threshold table, and outputs the highest-risk class. This is a strong baseline because the training labels come from these rules. The MLP should only be considered useful if it improves accuracy and macro-F1 on held-out data by handling noisy keypoints, body-size variation, and camera-angle variation better than hard thresholds.

\section*{Ethical Considerations}
MPOSE2021 contains pose data derived from human videos, so I must confirm that its terms permit academic use. Although raw images are not used, the source datasets may not represent all body types, ages, or ethnicities, so errors may be uneven across users. False negatives could make an athlete overtrust the system; it should be framed as a training aid, not medical advice or a safety guarantee. Any gym, sport, or workplace deployment must obtain informed consent because live pose tracking can become surveillance.
